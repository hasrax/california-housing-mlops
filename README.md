# California Housing MLOps

An end-to-end ML model service for house price prediction with request logging,
drift monitoring and automated retraining. Built phase by phase; see
[docs/architecture.md](docs/architecture.md) for the design and `docs/phase-*-notes.md`
for the decisions made in each phase.

Status: phase 0 (setup). The full README with results is written in phase 6.
